# 拼豆 App UI 设计草案 V1.1

## 动效原则
- 短、轻、明确。
- 服务操作反馈，不抢画布注意力。

## 动效规范
- 按钮点击: 缩放 0.98，80~120ms。
- 卡片点击: 阴影与高亮蒙层，120~180ms。
- Tab 切换: 颜色平滑 + 轻微上浮/胶囊，180~220ms。
- 色块选中: 缩放 1.05 + 描边 + 名称淡入，120ms。
- 工具切换: 选中态背景渐变，100~150ms。
- 底部弹层: 下滑入 + 透明度 0->1，220~280ms。
- 保存成功: 顶部提示条 1.2~1.8s。
- 错误提示: 轻微抖动 + 明确文案。

## 间距布局规范
- 4 的倍数体系: 4/8/12/16/20/24/32。
- 页面左右边距: 16。
- 卡片内边距: 16，大卡片: 20。
- 区块间距: 24。
- 卡片间距: 12~16。
- 顶部栏高度: 44~52。

## Design Tokens
- Color, Radius, Spacing, Typography, Shadow 按 `DESIGN_TOKENS_v1.1.md` 执行。

## 页面结构
- 首页: 顶部品牌区 + 核心操作区 + 最近作品 + 推荐模板 + 继续上次编辑。
- 模板页: 筛选(免费/付费) + 排序(热门/最新/入门) + 标签。
- 图片导入配置页: 优先项(输出尺寸、最大颜色) + 高级折叠参数。
- 编辑器页: 顶部栏 + 画布区 + 底部主工具区 + 次级操作区。
- 导出页: 导出预览 + 类型设置 + 统计确认。
- 我的作品页: 最近编辑/已完成/草稿。

## 空状态文案
- 首页最近作品: 还没有作品 / 从一张喜欢的图片开始，做出你的第一张拼豆图纸。
- 模板页: 没有找到相关模板 / 试试更换关键词或分类。
- 我的作品: 作品库还是空的 / 新建一个图纸，开始你的第一次创作。
- 导出记录: 暂无导出记录 / 完成作品后，可以在这里查看历史导出内容。

## 交互规则
- 首次引导: 2~3 条气泡提示。
- 二次确认: 删除作品、清空画布、覆盖导出、退出未保存项目。
- 自动保存: 草稿自动保存 + 状态可见化(已保存/保存中)。

## 实施顺序
1. 设计系统: colors.dart / spacing.dart / radius.dart / text_styles.dart / app_theme.dart。
2. 基础组件: AppScaffold / Buttons / AppCard / SectionHeader / ToolIconButton / ColorChip / PreviewCard / EmptyState / Skeleton。
3. 页面: 首页 -> 新建项目弹窗 -> 图片导入配置页 -> 编辑器 -> 导出页 -> 我的 -> 我的作品 -> 模板。
